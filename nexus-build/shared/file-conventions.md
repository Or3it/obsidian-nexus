# File & ID Conventions

**Status:** Contract.

## IDs

- **`thread_id`**: UUIDv7. Generate at thread creation, never changes.
- **`id-short8`**: first 8 characters of the UUIDv7 (without dashes). Used in filenames for human-scannability.
- **`handover_id`**: UUIDv7. Generated at handover creation.
- **`event_id`**: UUIDv7. Generated at each event log append.

UUIDv7 must be used (not UUIDv4) for chronological sortability. Use a library that supports it; do not roll your own unless RFC 9562 is followed exactly.

## Filenames

| Artifact | Pattern | Example |
|---|---|---|
| Live conversation | `Live/{YYYY-MM-DD}_thread-{id-short8}_{kebab-title}.md` | `Live/2026-05-13_thread-a1b2c3d4_designing-cascade.md` |
| Archived conversation | `Archive/{YYYY}/{MM}/{YYYY-MM-DD}_thread-{id-short8}_{kebab-title}.md` | `Archive/2026/05/2026-05-10_thread-e5f6g7h8_old-thread.md` |
| Handover | `Handovers/{id-short8}_handover_{sequence}.md` | `Handovers/a1b2c3d4_handover_01.md` |
| Per-thread event log | `Logs/{id-short8}.jsonl` | `Logs/a1b2c3d4.jsonl` |
| Daily orchestrator log | `Logs/orchestrator-{YYYY-MM-DD}.log` | `Logs/orchestrator-2026-05-13.log` |
| Daily plugin log | `Logs/plugin-{YYYY-MM-DD}.log` | `Logs/plugin-2026-05-13.log` |
| Conflict file | `Conflicts/{id-short8}_{ISO-timestamp-no-colons}.md` | `Conflicts/a1b2c3d4_2026-05-13T154712.md` |

## Title kebab-casing

- Generated by Haiku 4.5 from the first user turn (Phase 2+). In Phase 1, derive from the first 64 chars of the first user message.
- Lowercase, ASCII only, words separated by `-`, no leading/trailing dashes.
- Truncate to 64 chars after kebab conversion. Do not break a word at the cut.
- If empty after sanitisation, fall back to `untitled-{id-short8}`.
- User can rename via UI; the underlying `thread_id` and the canonical filename only change when user renames. Wiki-links continue to resolve because Obsidian uses filename without extension as link target — when renaming, also update inbound wiki-links in `related_threads` of any thread that points to this one. (Phase 4 concern; Phase 1 can leave a TODO.)

## Wiki-link conventions

- Conversation references: `[[2026-05-13_thread-a1b2c3d4_designing-cascade]]` (no extension, no path).
- Note references: `[[Note Title]]` exactly as the user has them.
- The orchestrator always emits wiki-links by filename-stem, never full path.

## Date/time format

- All timestamps: ISO 8601 with offset (`2026-05-13T14:32:00-05:00`), never naked `Z` and never naive.
- All dates in filenames: `YYYY-MM-DD` based on the user's local date at thread creation/archival.
- Phase 1 may default to UTC if the user's locale detection is deferred; document this.

## Encoding

- All vault files: UTF-8, LF line endings, no BOM.
- JSONL files: one JSON object per line, `\n` line endings, no trailing newline at EOF (or one — be consistent; recommend always one trailing newline).
